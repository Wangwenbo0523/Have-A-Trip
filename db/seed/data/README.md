# 中国 A 级旅游景区名录 · 数据集

本目录是 `db/seed/attractions_cn.sql` 的数据源：一份从**政府公开名录**规范化下来的
中国 A 级旅游景区清单，共 **1229** 条，覆盖 31 个省级行政区、233 个地市。

`cn_a_level.csv` 是唯一的人工维护入口。改数据改它，再跑
`python scripts/build_cn_attractions.py` 重新生成 SQL（脚本会先校验等级、slug 唯一性与必填字段）。

|---|---|
| 5A | 331 |
| 4A | 284 |

## 二、来源与口径

三个来源都是**政府部门公开发布的名录**（对应 `docs/LICENSE-AUDIT.md` 第三节里
「官方文旅部门公开名录、自行采集」一行的结论：推荐）。抓取时间为 2026-09。

| 来源 | 原始条数 | 收录 | 出处 |
|---|---|---|---|
| 广东省文化和旅游厅《广东省 A 级旅游景区名录表（截至 2026 年 8 月 31 日）》（5A 16 / 4A 218 / 3A 509 / 2A 11） | 754 | 742 | 省厅官网的 xlsx 附件（见「已知缺口」：精确页面地址未留存） |
| 北京市文化和旅游局《北京旅游网景点链接列表》（5A 10 / 4A 67 / 3A 105 / 2A 21 / 1A 2） | 205 | 179 | https://whlyj.beijing.gov.cn/ggfw/ly/202511/t20251119_4287815.html |
| 文化和旅游部旅游服务平台「全国 5A 级旅游景区」名录（逐条含省份、地市、地址、经纬度） | 359 | 308 | https://lyfw.mct.gov.cn/site/special/scenic |

### 合并规则

1. **省级名录优先，且独占该省级行政区。** 广东、北京两地完全取自省 / 市级官方名录，
   文旅部的全国 5A 名录**跳过**这两个省级行政区（25 条）。理由是省级名录更新也更细：
   北京 5A 记 10 家，文旅部把「八达岭—慕田峪长城」并作 1 家。
2. **与 `db/seed/seed.sql` 里已经自采的景点去重。** 去重键是「核心名 + 省级行政区」，
   核心名 = 去掉名称开头的城市前缀、再去掉末尾的「景区 / 风景区 / 风景名胜区 /
   旅游度假区 / 博物馆 / 公园…」等通用词。这样「杭州市西湖风景名胜区」不会和自采的
   「西湖」重复入库，「三亚市天涯海角游览区」也不会和「天涯海角游览区」并存。
   共剔除 30 条（广东 1、北京 3、文旅部 26），其中 29 条是 5A。
3. **同级同名同省去重**，剩下 1229 条，slug 全局唯一。

### 刻意没有收录

| 没有收录的东西 | 为什么 |
|---|---|
| 广东的 11 家 2A、北京的 21 家 2A 与 2 家 1A | `attraction.a_level` 的 CHECK 只允许 `5A / 4A / 3A`（`db/schema.sql`）。把 2A 写成空值与「留空 = 未核实」的口径冲突，宁可不收 |
| 广东、北京以外的 4A / 3A | 4A 及以下由各省评定、各省公布，全国没有统一名录。补齐要逐省到 29 个省级文旅厅官网抓取，本次没做（见「已知缺口」） |
| 文旅部接口里的 `introduce`（景区简介）与 `longitude` / `latitude` | 简介是平台上的成篇文字，不是名录本身，著作权状态与一份名单不是一回事，不引；坐标与 `db/README.md` 的口径冲突（一期不做地图与定位，坐标一律留空） |

## 三、字段

| 列 | 说明 |
|---|---|
| `slug` | 形如 `5a-guangdong-007`：`等级-省级行政区拼音-该省该等级的序号`。**定下就不要改**，它是 URL 的一部分 |
| `name` | 景区名称，取自名录原文，只做了空白归一 |
| `grade` | `5A` / `4A` / `3A` |
| `province` | 省级行政区全称（统一成「广东省 / 广西壮族自治区 / 北京市」这种写法） |
| `city` | 地市。省级名录给的是地市名，文旅部给的是它自己的 `city_name`（直辖市是区，如「东城区」） |
| `source` | 进库后写进 `attraction.source`，S5 的声明页按它聚合 |
| `source_url` | 可核验的页面地址；广东那一份没有留存精确地址，留空 |
| `license` | 统一为 `政府公开信息（官方名录）` |

## 四、已知缺口

- **4A / 3A 只覆盖广东与北京。** 这两级的评定权在省级，全国没有统一名录；补齐要逐省
  到各省文旅厅官网下载（多为 xlsx 附件，少数只在政务服务平台里提供查询接口）。
- **广东来源的精确页面地址缺失。** 下载时只留存了附件本身与表内标题（表名与截止日期
  可核验），栏目页地址没有记下来。
- **名录是动态的**：景区会新增，也会被摘牌。引用前请以文旅部与各省文旅厅最新公告为准。
- **去重用的是名称启发式**，「核心名 + 省份」相同即视为同一景区。个别同名但确实不同的
  景区可能被误合并，同一景区换了名称写法时也可能被同时收录。

## 五、怎么重新生成

```bash
python scripts/build_cn_attractions.py            # CSV -> db/seed/attractions_cn.sql
python scripts/build_cn_attractions.py --check    # 只校验磁盘上的 SQL 与 CSV 是否一致
python scripts/make_attraction_covers.py          # 封面与配图种子(与 seed.sql 的景点共用一套逻辑)
python scripts/make_attraction_covers.py --check  # 同上, 只校验不生成
```

两个 `--check` 都在 CI 的 `license-gate` 里跑: 手改了生成物、或改了这份 CSV 忘了重跑,
都会红。

原始下载件（广东 xlsx、北京 html、文旅部接口 JSON）体积较大，没有随仓库分发；
本目录只保留规范化后的 `cn_a_level.csv`。
